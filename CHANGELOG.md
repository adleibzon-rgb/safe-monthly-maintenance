# Changelog

## 1.0.2 — 2026-07-31

- Первый публичный релиз.
- Ежемесячный systemd timer с случайной задержкой.
- Безопасное APT-обновление без удаления пакетов.
- Проверки `dpkg`, свободного места и APT-lock.
- Очистка APT cache, systemd journal и временных файлов.
- Автоматическое определение нового ядра без автоматического reboot.
- `autoremove` и Docker prune выключены по умолчанию.
- Подробная документация и troubleshooting.
